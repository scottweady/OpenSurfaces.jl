API reference

OpenSurfaces — Module
OpenSurfaces

Singular integrals on flat open surfaces Ω ⊂ R² (the plane z = 0) and on their edges Γ = ∂Ω: the geometry and meshes, the standard kernels and kernels built from Fourier symbols (SymbolKernel), the local quadrature corrections, the fast sums (FMM, Ewald + NUFFT, smooth convolution) and the evaluators built from them (Evaluator, VolumePotentials, SingleLayer3D). Nothing here knows a physical model: a model passes its own kernels in, as callables or as SymbolKernels (a finite depth, an embedded membrane).

Kernel contract:

  • A point kernel is a callable K(r), or K(i, r) when it depends on the target i (as TractionKernel does through its normals). The quadrature accepts any callable (_wrap_kernel checks for K(i, r)).
  • It returns a value convertible to Mat2. Several scalar kernels may share the slots if documented (the volume potentials use row 1).
  • r = x − y is target minus source. Callers exclude coincident points, unless a kernel is documented as regular there.
  • Closed forms with parameters (G2(r; μ_2D), G3(r; μ_3D)) and two-argument forms (T2(r, n), stress2(r, f)) are functions; the standard kernels the quadrature and the evaluators dispatch on are types (StokesKernel, TractionKernel).
  • Model kernels live with their formulations (in the code that uses this package) and are passed in.

Boundary curves

OpenSurfaces.CurvePanel — Type

Boundary panel: a piece of Γ, γ(s) = Σ cₖ P_{k-1}(s), s ∈ [-1,1], traversed with the film on the left (outer curves counterclockwise, hole curves clockwise).

OpenSurfaces.discretize_curve — Function
discretize_curve(γ, p; tol=DEFAULT_TOL, maxlen=Inf, lfs_factor=1.0, nstart=8,
                 balance=true, maxpanels=100_000, return_params=false, lencap=nothing)

Adaptive panel discretization of the closed curve θ ↦ γ(θ) (2π-periodic, counterclockwise, returning anything convertible to Vec2). Only γ itself is needed: each panel is the degree p−1 interpolant at p Gauss–Legendre nodes in θ, and is bisected (in θ) until

  • resolution: norm of the last two Legendre coefficients ≤ max(tol × panel length, 1000 eps × curve size) (the second term is a rounding-error floor),
  • panel length ≤ maxlen, and ≤ lencap(x) at the panel midpoint x when a function lencap is given,
  • panel length ≤ lfsfactor × localfeaturesize (thin necks, near-contact, high curvature; lfsfactor = Inf disables),
  • balance: neighboring panel lengths differ by at most a factor 2 (if balance).

Returns Vector{CurvePanel} (each with p coefficients), or (panels, θbreaks) when return_params=true (panel k covers θbreaks[k] .. θbreaks[k+1]).

OpenSurfaces.discretize_curves — Function
discretize_curves(γs, p; gap_factor=4.0, return_params=false, kw...)

The curves of one film or plate (outline and holes) as by discretize_curve, each also limited to panels no longer than gap_factor × the distance from the panel midpoint to the other curves. discretize_curve sees one curve at a time, so a hole close to the rim (a narrow ring) would otherwise keep panels much longer than the gap, which the strip mesher cannot fit. Curves that are well separated are discretized exactly as by discretize_curve. Returns one result of discretize_curve per curve.

OpenSurfaces.reverse_curve — Function

Reverse the orientation of a closed panel curve (panel order reversed, s → −s on each panel).

OpenSurfaces.local_feature_size — Function
local_feature_size(panels; radius_factor=4.0, cosmax=0.0, nsamp=length(c))

Estimate of the local feature size of Γ at each panel, combining curvature and thickness:

lfs(x) = min( 1/|κ(x)|,  ½ min{ |x − y| : y ∈ Γ sample, n(x)·n(y) < cosmax } ).

The second term is a medial-axis style "half distance to the nearest part of Γ facing away from x": across a neck of half-width δ it gives ≈ δ; it also responds to near-contact of two parts of Γ from the outside. The search for y is limited to radius radius_factor × L (L the length of the panel containing x, the larger neighbor at a vertex); if nothing is found the thickness term is taken as Inf (callers choose the radius large enough that larger values would not matter).

Γ is sampled at each panel's start point and nsamp Gauss–Legendre points. Returns (vertex, panel, vertex_interior): lfs at the start vertex of each panel, the minimum over each panel (including both endpoints), and the interior-only variant at the vertices, min(1/κ₊, ½ distance to points y facing x through Ω: (y−x)·n(x) < 0 < (y−x)·n(y)), with κ₊ the convex part of the curvature. The interior variant is what limits the strip width (near contact from the outside and concave curvature do not), while the full lfs is used for panel lengths (quadrature accuracy).

OpenSurfaces.curve_area — Function

Area enclosed by the (closed, counterclockwise) panel curve: ½∮(x dy − y dx), exact up to rounding for polynomial panels.

OpenSurfaces.curve_length — Function

Length of the panel curve (the sum of panel_length).

OpenSurfaces.panel_length — Function

Arclength of the polynomial curve with Legendre coefficients c (GL quadrature).

Area meshes

OpenSurfaces.build_mesh — Function
build_mesh(panels, p; strip_factor=0.5, thick_factor=0.35, interior_size=Inf,
           size_factor=1.5, grading=0.5, jtol=0.05, shrink=0.8, clearance=0.5, maxfix=60,
           gmsh_options=(), edge_layers=3, edge_grading=0.2, coarse_interior=false)  ->  (bd, ad, info)

Build the boundary discretization bd = BoundaryDisc(panels, p) and the area discretization ad::AreaDisc of the domain enclosed by the counterclockwise panels.

Edge quads: panels 1:N of ad (N = length(panels)), edge quad k on boundary panel k. The strip width at boundary vertex v_k (start of panel k) is

h_k = min( strip_factor × min(L_{k−1}, L_k),  thick_factor × lfs(v_k) )

(L = panel lengths, lfs = interior local feature size from local_feature_size; thick_factor ≈ 0.35 keeps strips from opposite sides of a neck of half-width δ ≈ lfs apart), but at least 1.5× the inward bulge of the adjacent panels beyond their chords (so the top segment clears a concave bottom curve). h is then shrunk locally (×shrink, not below that bound) until every edge quad has min J > jtol × max J (checked at t = ±1 on a 3p-point Chebyshev grid in s; J is affine in t), top segments are not collapsed (≥ 0.2 × chord), and the inner polygon W is simple, does not cross Γ, and keeps a distance ≥ clearance × h from non-neighboring parts of W and Γ (so the interior region never gets pinched). If that fails, an error asks for boundary refinement.

Interior: gmsh Delaunay triangulation of W with target edge length

f(x) = min( interior_size,  min_k ( size_factor × ℓ_k + grading × |x − w_k| ) ),

ℓk the mean W-edge length at wk, recombined into quads by Blossom matching (W vertices kept as boundary nodes; for odd N one W edge gets a midpoint). Leftover triangles and non-convex quads (rare) are split into 3 quads each (centroid–edge midpoints). gmsh_options (name => value pairs) override gmsh options.

Coarse interior (coarse_interior = true): every other inner vertex wk (k even within each curve of ≥ 6 panels) is placed at the midpoint of w{k−1} and w{k+1}, so edge quads k−1 and k share one straight top segment, and gmsh meshes the polygon without these vertices (half as many boundary edges, so ℓk and the interior panels about double next to the strip; the interior is non-conforming at the dropped vertices, still an exact tiling). The strip checks above apply to the moved vertices; if the repair fails that way, or the panels' total area differs from the curves' (a tiling check), the full polygon is used. A dumbbell-shaped domain at tol 1e-6: 83.5k → 58.9k area nodes, same GMRES iterations and discretization error; the saving depends on gmsh's recombination (none for some meshes), hence off by default.

Edge layers: with edge_layers = L > 1 every edge quad is split in t into L layers with interfaces at (1+t)/2 = σ^{L−1}, …, σ (σ = edge_grading), i.e. geometrically graded toward Γ. Only the layer on Γ is weighted (panels 1..N); layer j ≥ 2 of edge quad k is panel N + (j−2)N + k (unweighted). All layers of edge quad k have bpanel = k (panel_groups groups them, and local_blocks gives an evaluator's dense block on each group, for a block-Jacobi preconditioner). The graded layers resolve the d^{1/2} log d edge terms (tangential forcing); default 3 layers at σ = 0.2.

info fields: h, W (inner vertices), lfs (interior lfs at boundary vertices), L (panel lengths), nedge, edgelayers, edgegrading, ninterior, nmerged (interior quads), nsplit (triangles split into 3 quads), ntriangles, tripoints, triangles, nsteinerW (extra nodes on W), nfix (repair iterations), ndropped (inner vertices left out of the interior by coarse_interior), times (NamedTuple).

build_mesh(curves::Vector{Vector{CurvePanel}}, p; kw...) -> (bd, ad, infos)
build_mesh(drops::Vector{Vector{Vector{CurvePanel}}}, p; kw...) -> (bd, ad, infos)

Several disjoint drops. In the first form each drop is one closed counterclockwise curve; in the second, drop i is drops[i] = [outer, hole₁, …] (outer counterclockwise, holes clockwise). Each drop is meshed by the single-drop build_mesh (same keywords) and the results are concatenated: drop i owns the boundary panels drop_panels(bd, i) (its curves drop_curves(bd, i), outer first) and the area panels drop_panels(ad, i), and the edge columns' bpanel refer to the global boundary panel numbering. infos[i] is drop i's info.

The drops are meshed independently: boundary panels facing a narrow gap are not refined for the other drop here (choose them so with discretize_curves).

Discretizations, drops and curves

OpenSurfaces.BoundaryDisc — Type
BoundaryDisc(panels, p; pstart, cstart)

The boundary Γ on its panels, with p Gauss–Legendre nodes per panel: nodes x, arclength weights w, unit tangents τ, outward normals n and signed curvatures κ (> 0 where Ω is locally convex). Panel k owns the nodes panel_nodes(bd, k). Several drops and curves: drop i owns the panels drop_panels(bd, i), closed curve c the panels curve_panels(bd, c) (each drop: its outer curve first, then its holes). Built by build_mesh.

OpenSurfaces.AreaDisc — Type
AreaDisc(panels, p; pstart)

The area mesh of Ω: ruled Panels with a p×p tensor grid of nodes each (s index fastest; panel k owns panel_nodes(ad, k)), the nodes x, their parameters st, Jacobians J and quadrature weights w = wₛ wₜ J. On a weighted panel (an edge panel, its bottom edge on Γ) a density is stored as μ̃ = μ (1 + t)^{1/2}, the t-rule is Gauss–Jacobi and its weight is folded into w; wfac = (1 + t)^{−1/2} there (1 elsewhere) gives μ = μ̃ · wfac. Drop i owns the panels drop_panels(ad, i). Built by build_mesh.

Kernels

Closed forms

OpenSurfaces.G2 — Function

2D Stokeslet: (1/(4π μ_2D)) (−log ρ I + r rᵀ/ρ²).

OpenSurfaces.G3 — Function
G3(r; μ_3D=1)

In-plane (2×2) block of the half-space Stokeslet on its free surface z = 0, (1/(4π μ3D)) (I/ρ + r rᵀ/ρ³): a fluid of viscosity μ3D below the surface. It equals the full-space Stokeslet at viscosity μ3D/2; for an unbounded fluid of viscosity μf, pass μ3D = 2μf.

OpenSurfaces.P2 — Function

2D Stokeslet pressure row: pressure = P2(r) ⋅ f = (1/(2π)) (r⋅f)/ρ².

OpenSurfaces.T2 — Function

2D traction kernel: the 2×2 matrix mapping a point force f at the source to the traction σ2(r)[f] n at the target with normal n, i.e. −(1/π) r (r⋅n) rᵀ/ρ⁴.

OpenSurfaces.stress2 — Function

2D Stokeslet stress tensor σ2(r)[f] = −(1/π) r rᵀ (r⋅f)/ρ⁴ (independent of μ_2D).

OpenSurfaces.LaplaceKernel2D — Type

(1/2π) log ρ, as (1/2π) log ρ · I.

OpenSurfaces.LaplaceGradient2D — Type

(1/2π) r/ρ², as the first column of a Mat2.

OpenSurfaces.BiharmonicGradient2D — Type

(1/8π) r (2 log ρ + c0), as the first column of a Mat2; c0 = −1 + 2κ − 2 log R.

OpenSurfaces.MHKernel — Type

Scalar kernel G = K₀(kρ)/2π (as the 2×2 kernel diag(G, 0) of the quadrature routines).

OpenSurfaces.MHNormalKernel — Type

Normal derivative at the target, ∂{nx}G = −k K₁(kρ)(r·n_x)/(2πρ).

The standard kernel types the quadrature dispatches on (not exported):

OpenSurfaces.StokesKernel — Type

Single-layer kernel G2(r; μ2D) + G3(r; μ3D); an infinite viscosity drops that term. G3 is the half-space Stokeslet (G3); for an unbounded fluid of viscosity μf, pass μ3D = 2μ_f.

OpenSurfaces.TractionKernel — Type

Traction kernel T2(r, n[i]) at target i.

Kernels from Fourier symbols

OpenSurfaces.SymbolKernel — Type
SymbolKernel(symbol; base, scale, far=nothing, remainder=nothing, outputs=nothing, ρc=30scale,
             nq=16, q=20, kmax=25/scale, dk=0.25/scale, kbreaks=nothing, regularize=false, tol=DEFAULT_TOL)

The kernel of a radial Fourier symbol, base plus a smooth remainder tabulated by Hankel transforms (head of src/kernels/symbol.jl).

  • symbol(k): a scalar ŝ(k), or the mobilities (a(k), b(k)) of an isotropic tensor kernel.
  • base: a standard kernel (Stokeslet3D, LaplaceKernel3D, or a kernel with a kernel_symbol method) that matches the symbol in two limits: at large k (the same singularity, so the remainder Δ decays and is smooth in real space) and at small k (k Δ integrable at k = 0, so the Hankel integrals converge; for a gradient output only, k³ Δ). The constructor throws when the remainder's integrals diverge at k = 0. Required: extracting the base from the symbol is not implemented.
  • scale: the length on which the remainder varies (the depth H); it sets the panels and the k grid and tells the fast sums how fine a grid resolves the remainder.
  • far(ρ): the remainder's outputs in closed form beyond ρc. Without it, evaluating beyond ρc is an error; callers that switch to their own far field read ρc.
  • remainder(k): Δ = symbol − base symbol in a numerically stable form (default: the difference).
  • outputs: for a scalar symbol, a tuple of :value, :gradient, :potential_gradient, :potential (default (:value, :gradient)); a tensor symbol gives (α, β).
  • regularize: the remainder's symbol is not integrable at k = 0 (head of the file); only :gradient, defined up to a multiple of r that the base fixes.
  • ρc, nq (Chebyshev points per panel), q (Gauss–Legendre points per k panel), kmax, dk, kbreaks: the table. kmax defaults to 25/scale, which suits a remainder that decays exponentially (as a finite depth's).
  • tol: for a remainder that decays algebraically (K.decay === :algebraic; then R has a cone or a log at ρ = 0), the default kmax grows (up to 64 ×) until the tail beyond it is below tol of |R(0)|, with a warning if it cannot. An Evaluator integrates such a remainder with the near corrections of the whole kernel, base + R. As a remainder of an Ewald sum it is refused (the long-range multiplier would sample the cone); an Evaluator of the SymbolKernel itself sums it by Ewald, its remainder split by weight between the long and the short range. A tensor one is tabulated as (α, A2/ρ), since β = −2A2/ρ² then grows like 1/ρ at ρ = 0 (kernel_remainder still returns (α, β), with β = 0 at ρ = 0).

Callable as K(r): base(r) plus the remainder (a Mat2 for a tensor symbol, a scalar otherwise). kernel_remainder(K, ρ) gives the remainder's outputs alone.

OpenSurfaces.Stokeslet3D — Type
Stokeslet3D(; μ_3D=1)

The in-plane (2×2) block, on the plane z = 0, of the Stokeslet of a half-space of viscosity μ = μ_3D below a free surface at z = 0 (a force on the surface, the fluid below it):

G(r) = (1/(4πμ)) (I/ρ + r rᵀ/ρ³),   symbol (1/(μk), 1/(2μk)),

G3(r; μ_3D = μ). This is the full-space Stokeslet at viscosity μ/2 (twice the Oseen tensor at μ): for an unbounded fluid of viscosity μf, pass μ3D = 2μ_f.

OpenSurfaces.EwaldStokes3D — Type
EwaldStokes3D(src, trg=nothing; μ_3D=1, remainder=nothing, tol=DEFAULT_TOL, σ=nothing, nneigh=150)

Plan for u(xᵢ) = Σⱼ G3(xᵢ − yⱼ) fⱼ (G3 the half-space Stokeslet at μ_3D; for an unbounded fluid of viscosity μf, pass μ3D = 2μf) with fixed source points src and targets trg (nothing: targets = sources). Coincident pairs are skipped, as by FMM3D and the direct sums: i = j, explicit targets that sit exactly on a source, and duplicated source points. σ defaults to the value giving about nneigh short-range neighbors per target. A remainder (a tensor SymbolKernel with base Stokeslet3D(), at μ = 1; e.g. a finite depth, RH = G_H − G3) is added to the long-range multiplier, all pairs including i = j, with σ small enough for the grid to resolve it on its scale.

whole = true: remainder is a tensor SymbolKernel K with base Stokeslet3D(; μ_3D) (its remainder in absolute units, any decay), and the plan sums K itself, coincident pairs skipped (R split by weight, _split_w).

OpenSurfaces.EwaldLaplace3D — Type
EwaldLaplace3D(src, trg=nothing; remainder=nothing, tol=DEFAULT_TOL, σ=nothing, nneigh=150)

Plan for u(xᵢ) = Σⱼ qⱼ / (4π|xᵢ − yⱼ|) (LaplaceKernel3D) with fixed source points src in the plane and targets trg (nothing: targets = sources). Coincident pairs are skipped, as by FMM3D and the direct sum: i = j, explicit targets that sit exactly on a source, and duplicated source points. σ defaults to the value giving about nneigh short-range neighbors per target. Apply with ewald_apply(E, q) (q includes the quadrature weights).

remainder: a scalar SymbolKernel K with base LaplaceKernel3D(): the plan sums K itself (1/(4πρ) plus its remainder R, which may decay algebraically), coincident pairs skipped; R is split by weight (_split_w).

OpenSurfaces.RadialEwald2D — Type
RadialEwald2D(kind, src, trg=nothing; k=0, out=:value, nd=1, tol=DEFAULT_TOL, σ=nothing, nneigh=150)

Plan for uᵢ = Σⱼ G(xᵢ − yⱼ) qⱼ with G = (1/2π) log ρ (kind = :log) or K₀(kρ)/2π (:mh, wavenumber k), sources src, targets trg (nothing: targets = sources), coincident pairs skipped. out = :value (nd densities at once: q is nsrc × nd) or :gradient (∇ₓ, one density; the result a Vec2 per target). Apply with ewald_apply(E, q).

OpenSurfaces.area_correction — Function
area_correction(ad, K; targets=nothing, target_info=nothing, tol=DEFAULT_TOL,
                near_factor=nothing, opts=nothing, detect_on_panel=true,
                transposed=false, stats=nothing) -> SparseMatrixCSC

Sparse correction C (2Nt × 2N, interleaved) such that, for the area potential u(xᵢ) = ∫Ω K(xᵢ − y) μ(y) dAy,

u(xᵢ) ≈ Σ_{j ≠ i} K(xᵢ − x_j) w_j μ̃_j + (C μ̃)ᵢ          (smooth rule as in the FMM).
  • targets === nothing: targets are the area nodes; the smooth-rule self term (j = i) is excluded (it is 0 in the FMM).
  • targets::Vector{Vec2}: arbitrary targets; the smooth rule includes all j (except sources coinciding exactly with the target). target_info[i] = (k, (s0,t0)) declares that target i lies on panel k at parameters (s0,t0) (e.g. Γ nodes: boundary_target_info); k = 0 means no information. With detect_on_panel=true targets lying on other near panels (shared sides/corners) are detected automatically by a Newton solve.
  • K: K(r)::SMatrix{2,2} or the target-dependent K(i, r) (i = target index), e.g. a traction kernel with the normal of target i.
  • transposed=true returns Cᵀ (2N × 2Nt), which is what is assembled internally (saves a copy).
  • stats: optional Dict to receive statistics (pairs, kernel evaluations, nnz).
  • upsampling::AreaUpsampling: the far field is evaluated from the upsampled rule instead of the nodes; the corrections subtract the upsampled smooth weights and the near radius shrinks.
  • keep(i, k)::Bool: correct only the near (target, panel) pairs it accepts; the others keep the smooth rule (e.g. only pairs from different drops).
OpenSurfaces.area_local_weights — Function
area_local_weights(ad, k, x0, K; on=:auto, tol=DEFAULT_TOL, opts=nothing, itarg=0)

Accurate local weights of panel k for the target x0: a vector of p² 2×2 blocks W[m] (node order of panel_nodes(ad,k)) such that ∫panel K(x0 − y) μ(y) dA ≈ Σm W[m] μ̃_m. K is K(r) or K(i, r) (then called with i = itarg). on: (s0,t0) if x0 = x(s0,t0) lies on the panel, nothing if it does not, :auto to detect it.

OpenSurfaces.AreaQuadOpts — Type
AreaQuadOpts(p; tol=DEFAULT_TOL, near_factor=nothing, ...)

Parameters of the local area quadrature. tol is the target accuracy (relative to the size of a panel's contribution). near_factor: a (target, panel) pair is corrected when |x − ck| < nearfactor · Rk (ck panel center, R_k its circumradius); by default it is derived from p and tol such that the p×p smooth rule is accurate to ≈ tol outside, and at least 1.2 (targets near a neighboring panel's corner).

The polar rule's sizes also have floors set by the Lagrange basis: its degree along a line is p − 1 in s and t on plain panels, but 2(p − 1) in σ or z on weighted panels (t = −1 + 2σ², v = z²), up to 3(p − 1) along a radial line. The floors integrate the basis to ≈ tol/10: each is its p = 10 size for ≈ 1e-10 plus the measured extra points per digit (2.2 digits per side point, 0.9 per inner radial point). The adaptive side rule adds ⌈d/2⌉ points to the kernel's estimate _qneed(ρ, qtol), d the basis degree along the side: Gauss–Legendre is exact to degree 2q − 1, so the basis factor spends d/2 of the ρ^{−2q} rate (without it the weights miss by up to 24 × tol at tol 1e-6 and 240 × tol at 1e-8). With the shift the side rule meets ≈ tol/10 at its own qtol_v = tol/2 (10 × qtol, which the off-panel boxes keep). floors = false restores the tol-only sizes, without either.

OpenSurfaces.AreaUpsampling — Type
AreaUpsampling(ad, q)

Upsampled tensor rule on every panel (q×q; Gauss–Legendre in s, Gauss–Legendre or Gauss–Jacobi (weighted panels) in t). Densities are interpolated from the p×p nodes with the reference matrices Iu/Iw (q² × p², s index fastest), so the far field can be evaluated from the points x with weights w (Jacobi weight and Jacobian included). With a q-point rule the smooth quadrature is accurate closer to a panel, so fewer (target, panel) pairs need corrections.

OpenSurfaces.Evaluator — Type
Evaluator(K, ad::AreaDisc; targets=:area, bd=nothing, density=:stored, fast=:auto, remainder=nothing,
          plan=nothing, tol=DEFAULT_TOL, eps=tol, near_factor=nothing, opts=nothing, upsampling=nothing)
Evaluator(K, bd::BoundaryDisc; targets, fast=:auto, tol=DEFAULT_TOL, eps=tol)

The potential of kernel K from area (or boundary) sources at targets: :area (the area nodes), :boundary (the nodes of bd), a vector of points, or a tuple of these (one fast sum, an output per set). E(f) gives the potential for the density f at the source nodes (scalars or Vec2, by kernel_shape(K)); evaluator_matrix(E) the dense matrix of a direct-sum evaluator.

  • density: :stored takes the mesh's own values (edge-weighted on its weighted panels); :smooth physical nodal values of a smooth density, integrated on the unweighted copy of the mesh.
  • fast: :auto (by the kernel's type: Ewald for Stokeslet3D, LaplaceKernel3D and a SymbolKernel of either base, FMM2D for the 2D kernels, direct sums for other callables), :ewald, :fmm, :direct.
  • remainder: a SymbolKernel added to K (head of src/evaluators/evaluator.jl); for Stokeslet3D at μ = 1 (scaled with K), into Ewald's multiplier; for LaplaceKernel3D and BiharmonicGradient2D without a far field, a local sum over the pairs closer than ρc (where the kernel's tail falls below eps).
  • plan: an existing EwaldStokes3D (EwaldLaplace3D: targets = all the sets, concatenated) plan of the same sources and targets to reuse.
  • near_factor, opts, upsampling: passed to area_correction. With an AreaUpsampling of ad (stored densities, no remainder) the fast sum runs over its points, the density interpolated to them (upsample).
  • tol: the local corrections; eps: the fast sum (fixed here for Ewald and the local sum of a remainder; per call E(f; eps) for the FMMs).

As a linear operator (one target set) on interleaved Float64 vectors (plain ones for a scalar kernel): size(E), mul!(y, E, x), E * x; evaluator_matrix(E) is its dense matrix and local_blocks(E, groups) the diagonal blocks of panel groups (panel_groups).

OpenSurfaces.kernel_shape — Function
kernel_shape(K) -> (nout, nin)

The slots of a kernel's 2×2 form that its potential uses: (1, 1) a scalar kernel (slot [1, 1]; the default), (2, 1) a vector kernel (the first column), (2, 2) a tensor kernel. A kernel of your own that is not scalar declares it, OpenSurfaces.kernel_shape(::MyKernel) = (2, 2); Evaluator probes the kernel once and throws if a kernel taken as scalar returns a 2×2 form with entries outside slot [1, 1] (a plain closure cannot declare a shape: wrap it in a type).

OpenSurfaces.evaluator_matrix — Function
evaluator_matrix(E) -> Matrix

The dense matrix of an Evaluator with one target set, acting on the density at the source nodes: the smooth rule (coincident pairs skipped; a remainder over all pairs, with R(0) at coincident ones; a local sum within its cutoff), plus the corrections. Its layout is the kernel's shape: Nt × N (scalar), 2Nt × N (vector kernel), 2Nt × 2N (tensor), interleaved, so M * interleave(f) ≈ interleave(E(f)) (scalar: M * f ≈ E(f)); for a fast sum, to its eps. With density = :smooth or upsampling, the interpolation from the nodes is included.

OpenSurfaces.local_blocks — Function
local_blocks(E, groups) -> (idx, blocks)

The diagonal blocks of evaluator_matrix(E) on groups of area panels (e.g. panel_groups(ad)): for each group, the indices idx[g] of its unknowns in the evaluator's layout (interleaved for a tensor kernel) and the dense block blocks[g] (the smooth rule within the group plus the corrections, from the nodal density). For an evaluator whose targets are its source mesh's nodes (targets = :area, a scalar or tensor kernel, no upsampling); e.g. a block-Jacobi preconditioner applies blocks[g] \ y[idx[g]] on each group.

OpenSurfaces.panel_groups — Function
panel_groups(ad; group=true) -> Vector{Vector{Int}}

Groups of area panels for block preconditioners: each edge column (the panels over one boundary panel: the weighted layer and the graded layers above it, thin and strongly coupled) and each interior panel alone; group = false: one group per panel.
